🚀 Schnellstart

git clone https://github.com/jbkunama1/hAI.LLDesignShop.git
cd hAI.LLDesignShop
cp .env.example .env
docker network create highfishNetwork
docker compose up -d

Dann EverShop Admin unter http://<host>:3000 aufrufen.
