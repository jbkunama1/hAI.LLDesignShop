📖 Über LauraLieDesign

Bei uns dreht sich alles um den schönsten ersten Schultag: handgefertigte Stoff-Schultüten (Zuckertüten) für kleine Schulanfänger:innen – liebevoll genäht, mit viel Liebe zum Detail und in wiederverwendbarer Stoffqualität, die weit über den Einschulungstag hinaus Freude bereitet. Ob mutiger Ninja, funkelndes Einhorn, wilder Dino, starker Superheld oder elegante Wildkatze – jede Schultüte wird einzeln gefertigt und individuell auf die Wünsche eures Kindes abgestimmt. Handgefertigt und versendet aus Deutschland 🇩🇪.

🧩 Technische Architektur

Der Shop läuft komplett selbstgehostet, unabhängig von Etsy & Co., als ein Docker-Compose-Stack.

🐘 PostgreSQL — evershop_db
↓
🛒 EverShop — Port 3000 · GraphQL + Admin-UI
↓ GraphQL Sync (optional)
🤖 Telegram-Bot — aiogram · SQLite
↓
💬 Kunden im Telegram-Chat
↓
🌐 Kunden im Webshop

✨ Features

🎒

Handgefertigte Unikate

Jede Stoff-Schultüte wird einzeln genäht – Motive wie Ninja, Einhorn, Dino, Superheld & Wildkatze.

🤖

Telegram-Shop-Bot

Direktverkauf im Chat mit /shop, /cart und /checkout – eigene SQLite-DB, kein Overhead.

🛒

EverShop Webshop

GraphQL-API, React-Frontend, PostgreSQL – voller Admin-Bereich für Katalog & Bestellungen.

🐳

Docker & Portainer

Ein docker-compose.yml für den kompletten Stack, direkt als Portainer-Stack importierbar.

💳

Zahlungsoptionen

Manuelle Freigabe zum Start, Telegram Payments API (Stripe) für automatisierte Abwicklung vorbereitet.

🇩🇪

Made in Germany

Handgefertigt und versendet aus Deutschland – persönlicher Service, direkt und ohne Umwege.

🚀 Schnellstart (für Betreiber)

# 1️⃣ Repository klonen
git clone https://github.com/jbkunama1/hAI.LLDesignShop.git
cd hAI.LLDesignShop

# 2️⃣ Umgebungsvariablen vorbereiten
cp .env.example .env
nano .env

# 3️⃣ Stack starten
docker compose up -d

# 4️⃣ Logs checken
docker compose logs -f
